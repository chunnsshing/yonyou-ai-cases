# Demo videos and dashboards

Put each scenario's demo in the folder named after its id, e.g.
`videos/sales-po-email-to-do/demo.mp4`.

- Videos: .mp4 .mov .m4v .webm
- Result dashboards: .html (Play Demo opens the page directly)

Several files in one folder are shown in filename order (01-intro.mp4, 02-flow.mp4 …).
Any scenario with a file here automatically gets the "Ready" tag.

Then run `python build.py` (or push: GitHub Pages rebuilds automatically).
